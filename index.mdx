## Démarrage rapide

Commencez à utiliser l'API VoiceHire en 3 étapes simples :

<Steps>
  <Step title="Obtenez votre clé API">
    Connectez-vous à votre compte VoiceHire et générez une clé API depuis les paramètres
  </Step>
  <Step title="Faites votre première requête">
    Testez votre connexion en vérifiant vos crédits disponibles
    ```bash
    curl -X GET https://app.voicehire.io/api/v1/account/credits \
      -H "X-API-Key: vh_live_VOTRE_CLE_API"
    ```
  </Step>
  <Step title="Créez votre première campagne">
    Lancez une campagne de recrutement avec génération automatique des questions
    ```bash
    curl -X POST https://app.voicehire.io/api/v1/campaigns \
      -H "X-API-Key: vh_live_VOTRE_CLE_API" \
      -H "Content-Type: application/json" \
      -d '{
        "job_title": "Commercial B2B",
        "contract_type": "CDI",
        "job_description": "Description du poste..."
      }'
    ```
  </Step>
</Steps>

## Cas d'usage

L'API VoiceHire est idéale pour :

- **Intégration ATS** : Connectez VoiceHire à votre système de suivi des candidatures
- **Automatisation** : Créez des workflows automatisés pour vos campagnes de recrutement
- **Applications custom** : Développez des applications personnalisées utilisant VoiceHire
- **Reporting avancé** : Créez des tableaux de bord personnalisés avec vos données
